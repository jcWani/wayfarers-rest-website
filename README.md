## About The Project

<p align="center">
An immersive booking platform built with Next.js, Supabase, and Tailwind CSS, inspired by The Ultimate React Course 2024 by Jonas Schmedtmann. This project showcases a seamless way to browse and reserve cozy cabins.
</p>

![Screenshot](/public/home.png)

<!-- APPLICATION'S FEATURES -->

## 📝 Features

- Discover & Book: browse rooms with rich details and real-time availability.

- Google Sign-In: quick and secure authentication.

- Manage Reservations: modify or cancel bookings easily.

- User Profiles: personalize and update account details.

<!-- TECHNOLOGY USED -->

## 👨‍💻 Tech Stack

- **Next.js**: Server-rendered React for performance and SEO..

- **Supabase**: Real-time backend and database.

- **Auth.js**: Secure authentication.

- **Tailwind CSS:**: Modern utility-first styling.
